Sistema de Classificação Automática de Emails

Uma aplicação web que utiliza inteligência artificial para classificar emails em categorias produtivas ou improdutivas e gerar respostas automáticas adequadas.

🚀 Funcionalidades

  • Upload de arquivos: Suporte a arquivos .txt e .pdf
  • Entrada de texto direto: Cole o conteúdo do email diretamente
  • Classificação automática: Identifica se o email é produtivo ou improdutivo
  • Geração de respostas: Sugere respostas automáticas baseadas na classificação
  • Interface intuitiva: Design moderno e responsivo

🛠️ Tecnologias Utilizadas

  • Backend: Flask (Python)
  • Frontend: HTML5, CSS3, JavaScript
  • IA/NLP: Hugging Face Transformers API
  • Processamento de texto: NLTK
  • Hospedagem: Render/Railway

Plataforma de vendas com automação via WhatsApp
Loja virtual, pagamentos e acompanhamento automatizado
Projeto freelancer desenvolvido para automatizar o processo comercial de uma loja.
A plataforma permite gerenciar produtos, categorias, catálogo e pedidos. Após a realização de uma compra, o sistema inicia automaticamente um fluxo de mensagens pelo WhatsApp para acompanhar o cliente durante a finalização do processo.
O pagamento foi integrado ao Mercado Pago, permitindo criar transações, acompanhar seu status e confirmar o pagamento do pedido.
Funcionalidades
Gerenciamento da loja
Cadastro e edição de produtos
Organização por categorias
Gerenciamento de catálogo
Criação e acompanhamento de pedidos
Integração com o Mercado Pago
Confirmação de pagamentos
Atualização do status dos pedidos
Automação de mensagens pelo WhatsApp
Fluxo pós-compra
Painel administrativo
Fluxo da solução
O cliente realiza a compra no site.
O sistema registra o pedido.
O pagamento é processado pelo Mercado Pago.
O cliente recebe uma mensagem automática pelo WhatsApp.
Um fluxo de mensagens acompanha a finalização da compra.
A confirmação do pagamento atualiza o pedido.
A empresa acompanha a operação pelo painel administrativo.
Minha participação
Fui responsável pelo desenvolvimento da plataforma, incluindo módulos administrativos, regras de negócio, integração com o Mercado Pago, automação de mensagens pelo WhatsApp, banco de dados e implantação da aplicação.
Resultado
A solução centralizou a administração da loja e automatizou a comunicação pós-compra, reduzindo a necessidade de acompanhamento manual dos pedidos.
